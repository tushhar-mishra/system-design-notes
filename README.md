# System Design for DevOps / SRE / Platform Engineers

One self-contained learning path for system design, from "what happens when you type a URL" to designing, defending and troubleshooting production systems in a senior DevOps/SRE/Platform interview.

Start at **[INDEX.md](INDEX.md)**. Topic files are in [`notes/`](notes/), numbered in reading order.

**Status:** ✅ Complete: 62 topics in 11 parts. Foundations (networking, DNS, load balancing, caching, databases, queues, scalability, availability) → DevOps/SRE design (observability, SLOs, CI/CD, deployments, IaC, Kubernetes platforms, security, DR, multi-region, cost) → 13 interview-style case studies → interview readiness.

**Every concept topic has the same shape:** ⚡ Core (10-minute version) · What it is · Why it exists · Analogy · How it works inside · Options and trade-offs · Failure modes · Where you'll use it · Design exercise · Quick recap + interview questions.
